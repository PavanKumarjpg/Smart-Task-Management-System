# Smart Task Management System

A simple full-stack task management application built using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven
- REST API

## Features

- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Set task priority
- Set task status
- Store tasks in MySQL database
